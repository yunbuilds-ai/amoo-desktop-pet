# Asset pack layout

The build takes an explicit media folder containing `character/manifest.json`, `character/poster.png`, `character/tray.png` and the files `animations/<id>.webm` and `animations/<id>.webp`. The manifest registers the eight action IDs listed in the [README](../README.md).

Character art is tracked under a [separate rights policy](../ASSETS_LICENSE.md). Use an approved pack.
