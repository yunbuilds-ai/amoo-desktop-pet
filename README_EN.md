# Amoo Desktop Pet

**Amoo 桌宠**

An unofficial, open-source desktop pet featuring an orange-gold chibi companion.

**v1.0.0-rc.2 · Community Preview candidate**　[中文](README.md)

The pet uses transparent animations, reacts to clicks, can be dragged or thrown, and lives in the Windows system tray. AI and network services are off by default.

## Download and run

Reviewed Windows x64 portable builds will appear on the repository's Releases page when publication is approved. Extract the entire ZIP and open `AOMM Companion.exe`. Name any desktop shortcut **Amoo Desktop Pet**. The preview runs offline. See [build instructions](docs/BUILD.md) for source builds.

## Controls and motions

- Click the pet for a reaction. Drag to move it. Enable the tray's throw setting for release momentum.
- The tray controls visibility, click-through, size, always-on-top, motion preferences, additional instances and exit. Use `Ctrl+Alt+Shift+P` to show the pet and restore clicking.
- The character pack contains eight motions: idle, greeting, tap reaction, reply, happy, confused, thinking, and reminder. Reply, thinking and reminder are registered animations available to local source examples.
