# Changelog

## 1.0.0-rc.1 · Community Preview candidate

- The public product name is Amoo Desktop Pet (Amoo 桌宠).
- Standalone Windows x64 portable packaging with a fixed Electron dependency.
- Eight registered transparent motions with RGBA compatibility playback.
- A persistent display canvas retains a valid frame across decoder handoffs. The static fallback uses a matching idle pose.
- Desktop click reactions, dragging, optional throw, tray controls and multiple local instances.
- Source builds take a separately approved character pack.
