## 🌟 认识 Amoo

**Amoo 桌宠**是一款轻量、可爱且富有互动感的 Windows 桌面宠物软件。

Amoo 可以自由地出现在你的电脑桌面上，通过生动的表情、自然的动作和趣味互动，为日常使用增添一份陪伴与乐趣。

无论是安静地待在桌面、向你挥手打招呼，还是对鼠标点击作出回应，Amoo 都能以自己的方式与你互动。

## ✨ 功能特色

- **动态陪伴**：支持待机、打招呼、开心、困惑、思考、回复等八组基础动画。
- **桌面互动**：点击 Amoo，即可获得可爱的互动反馈。
- **自由拖动**：可自由移动 Amoo，支持拖动、甩动与反弹效果。
- **透明窗口**：独立透明桌宠窗口，支持置顶显示。
- **多实例运行**：可以同时开启多个 Amoo。
- **系统托盘**：支持显示、隐藏、恢复及退出。
- **离线运行**：无需安装 DSH，也无需连接 AI 模型，即可使用基础功能。
- **开源扩展**：提供桌宠源代码，欢迎社区参与改进。

## 📥 下载 Amoo

**当前版本：v1.0.0-rc.2 Community Preview**

### [📦 点击下载 Windows 版本](https://github.com/yunbuilds-ai/amoo-desktop-pet/releases/tag/v1.0.0-rc.2)

**安装方法**

1. 进入上方下载页面。
2. 下载 `Amoo-Desktop-Pet-v1.0.0-rc.2-windows-x64.zip`。
3. 将 ZIP 完整解压到电脑文件夹。
4. 双击 `AOMM Companion.exe` 启动。
5. 开始与 Amoo 互动！

当前支持 Windows x64 平台。

## 🎮 如何与 Amoo 互动

| 操作 | 效果 |
|---|---|
| 鼠标点击 Amoo | 触发互动反馈 |
| 按住鼠标拖动 | 自由移动桌宠 |
| 快速甩动 | 开启对应设置后触发甩动效果 |
| 系统托盘 | 控制桌宠显示、隐藏和退出 |
| 动作菜单 | 播放已提供的桌宠动画 |
| 多实例 | 同时运行多个 Amoo |
