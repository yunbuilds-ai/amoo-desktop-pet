# Amoo 桌宠 / Amoo Desktop Pet

**让 Amoo 来到你的桌面，成为日常陪伴的一部分。**

Amoo 桌宠是一款轻量、可爱且富有互动感的 Windows 桌面宠物软件。

Amoo 可以自由地出现在电脑桌面上，通过丰富的动态表情和自然的互动反馈，为日常使用增添一份生动与趣味。

无论是安静待机、向你打招呼，还是回应鼠标点击，Amoo 都能以自己的方式陪伴你。

## ✨ 功能特色

- **动态陪伴**：支持待机、打招呼、开心、困惑、思考、回复等八组基础动画。
- **桌面互动**：点击 Amoo 即可获得有趣的互动反馈。
- **自由拖动**：可以将 Amoo 放在桌面的不同位置，支持甩动与反弹效果。
- **透明桌宠**：独立透明窗口，支持置顶显示，不影响正常桌面使用。
- **多实例运行**：支持同时开启多个 Amoo。
- **轻量独立**：无需安装 DSH 或连接 AI 模型，即可使用基础桌宠功能。
- **开源扩展**：提供源代码，欢迎社区参与改进与功能扩展。
