# Amoo 桌宠

**Amoo Desktop Pet**

一款橙金 Q 版少女 Windows 桌面宠物，支持透明动画和桌面互动。

**v1.0.0-rc.1 · Community Preview 候选**　[English](README_EN.md)

橙金少女可待在桌面一角。单击可互动，拖动可移动，开启甩动后可以抛掷。八组动作均走同一透明播放器，网络与 AI 服务默认关闭。

## 下载与启动

经审核的 Windows x64 便携包发布后将在仓库 Releases 页面提供。解压完整目录，双击 `AOMM Companion.exe` 即可离线启动。创建桌面快捷方式时，将快捷方式命名为 **Amoo 桌宠**。源码构建见[构建说明](docs/BUILD.md)。

## 桌面操作

| 操作 | 行为 |
| --- | --- |
| 左键单击角色 | 点击反馈 |
| 按住角色拖动 | 移动角色。开启托盘中的拖拽甩动后可抛掷 |
| 托盘菜单 | 显示、隐藏、置顶、缩放、动作设置、新增同款桌宠与退出 |
| 透明区域 | 鼠标穿透。可通过托盘恢复点击 |
| `Ctrl+Alt+Shift+P` | 恢复桌宠显示与点击 |

动作库包括待机、打招呼、点击反馈、回复、开心、困惑、思考／等待、提醒。待机、首次招呼和本地互动由桌面行为触发。回复、思考和提醒是可用的动作资源。
